# Fetch and display epics from aardstats.com

## Commands

Channel is optional and will be 'echo' unless specified.

- `listhelp` Lists commands.
- `listday` Displays today's epics in specified channel. Example `listday` or `listday gt`
- `listnext [channel]` Displays next epic in specified channel. Example `listnext spouse`
- `listall [channel]` Displays all remaining epics in specified channel. Example `listall spouse`
- `listepic [name] [channel]` Displays remaining epics of that type in specified channel. Example `listepic inferno spouse`
